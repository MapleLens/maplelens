Built to stay out of trouble

MapleLens only does what a screenshot tool does. Anti-cheat software looks for programs that change the game or play it for you; MapleLens does neither.

Screen pixels only

It copies what is already on your screen, the way OBS or Discord screen sharing do (the store watcher uses the same window capture as OBS, so it keeps watching behind other windows). It never reads or writes the game's memory and never injects anything.

Never touches the game

It does not even open the game's process: it finds the game window by name in the system's window list, like the share dialog does.

You do all the playing

No key presses, no clicks, no keyboard hooks. The overlay is click-through, never takes focus, and only shows while the game is in front.

No outside tool can be promised to be safe: NEXON's terms ban "unauthorized third-party software". MapleLens is open source so anyone can check that it does only what is described here.
